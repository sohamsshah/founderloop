      Simulated story: nothing is sent anywhere

      How it works

      FounderLoop is a Node.js agent that listens to authorized Switch rooms over a WebSocket. Ordinary messages can trigger the flow without a mention, and source rooms are read-only for the agent.

      Verify the message and add context

      Every founder card includes the verbatim quote and a link to the exact message. FounderLoop holds a signal if it can’t verify that link. Product checks the roadmap in Google Docs, Revenue looks for account context in a Leads Sheet, and Commitment surfaces incidents or explicit promises from trusted staff. An optional General route covers direct requests for the founder.

      Decide in private Slack

      The authorized founder can accept, reject, or comment with a Slack button or a text command. FounderLoop records one decision per card and sends the verdict with the same source link. The card closes when Switch acknowledges the verdict.

      Keep a record across restarts

      SQLite stores the source evidence, decision, and delivery queue. If a send may have succeeded, FounderLoop holds it for an operator to check before retrying.
