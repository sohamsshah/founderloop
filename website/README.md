# FounderLoop site

Two static pages, no build step.

- `index.html`: the main post (walkthrough, technical details, Switch sections)
- `build-your-own.html`: the separate "Build your own FounderLoop" page

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, Vercel).

Notes:
- Fonts load from Google Fonts. Without network the page falls back to system fonts.
- The Switch wordmark is embedded from the Switch project's open-source repo.
- The walkthrough is simulated and never contacts Discord, Slack or Switch.
